# Applied Storage Research (ASR)

## Description

The Applied Storage Research (ASR) organization (llnl-asr) and its projects are intended to contain open-source software, tools, frameworks, and representative benchmarks for research and development in data management, storage, I/O, provenance, and performance analysis for high-performance computing (HPC) and data-intensive systems.

The ASR organization and its projects are intended to provide reusable research software that helps developers and researchers observe, understand, analyze, diagnose, and improve how data is generated, accessed, moved, managed, and used across large-scale computing systems. The organization and its projects may include:

- Monitoring and tracing tools for observing application, data, and system I/O behavior.
- Data provenance and lineage tools for capturing how data is generated, transformed, moved, and consumed across workflows, supporting reproducibility, traceability, and FAIR (Findable, Accessible, Interoperable, and Reusable) data principles.
- Large-scale data analytics frameworks for analyzing performance, provenance, and behavioral data produced by monitoring and tracing systems.
- I/O middleware solutions for improving data movement, storage access, and interactions between applications and storage systems.
- Bottleneck detection and optimization tools for identifying performance problems, understanding their causes, and assisting with targeted improvements.
- Representative benchmarks and proxy workloads that reproduce important I/O and data-access behaviors without distributing the original scientific applications or their datasets.
- Dashboards and visualization tools for exploring application behavior, data movement and provenance, system behavior, and performance-analysis results.
- Agentic interfaces and frameworks that assist users in interacting with these tools, exploring provenance and performance data, diagnosing problems, improving reproducibility, and identifying potential optimizations.

Together, the ASR organization and its projects are intended to support research toward high-performance, explainable, reproducible, and FAIR data ecosystems for large-scale computing.

The ASR organization and its projects are intended to serve as a common home for open research software developed around applied storage and data-management research and to encourage reuse, interoperability, and collaboration across projects.

### Scope

The ASR organization and its projects are not intended to contain scientific application codes or application datasets. Representative benchmarks and proxy workloads may reproduce selected I/O patterns, data-access characteristics, workflow structures, or performance behaviors of real applications, but are not intended to include the corresponding scientific application source code or scientific datasets.

The ASR organization and its projects are intended to focus on the tools, systems, middleware, provenance infrastructure, analysis frameworks, benchmarks, visualization systems, and intelligent interfaces surrounding scientific data and I/O, rather than on the scientific applications or their data themselves.
